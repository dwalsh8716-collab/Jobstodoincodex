# David Walsh Tone Of Voice

Use this for every Essential Resourcing page, component, CMS field label, CTA, FAQ, insight, job, case study and proof placeholder.

## Core Voice

Write like David Walsh.

Plain English. Warm. Northern. Straight-talking. Commercial. Human. No faff.

The client is the main character, not the recruiter.

Focus on the problem behind the hire and the outcome the client needs. Do not lead with databases, process or generic recruiter claims.

Sound like a smart, experienced recruiter who would say it on a call.

Use short sentences. Real language. A bit of edge where natural. Light humour is fine, but do not force it.

## Core Messaging Principle

The job title is rarely the real brief.

A client might say:

> We need a Head of Marketing.

But what they often mean is:

- We need someone to bring structure.
- We need someone to generate more demand.
- We need someone to lead the team properly.
- We need someone who can work with the board.
- We need someone to stop the founder doing everything.
- We need someone to improve performance.
- We need someone to build confidence internally.
- We need someone to help us grow.

Essential Resourcing’s value is not just finding candidates. The value is understanding what the business actually needs, then finding the person who can deliver it.

## Copy Rules

For every section, ask:

- Would David actually say this?
- Would an agency founder think, “he gets it”?
- Would a CMO think, “clear, useful and credible”?
- Does this make the client the main character?
- Does this talk about the outcome before the process?
- Could any other recruitment website have written this?

If the answer is wrong, rewrite it.

If the copy leads with “we”, rewrite it so it starts with the client’s situation, problem or desired outcome.

If it talks about process before problem, rewrite it.

If it is vague, make it sharper.

If it sounds like normal recruiter copy, delete it and write something useful.

## Hero Direction

The homepage can carry the stronger brand line:

```txt
Hire good people.
No faff.
No d!ckheads.
```

Keep “No d!ckheads” as a strong brand moment, not the whole personality of the site.

Senior service pages should be cleaner:

```txt
Senior marketing and comms hiring, done properly.
```

## CTA Language

Use CTAs that sound natural and useful:

- Talk through a hiring challenge
- Sense-check a brief
- Talk to David
- Get honest market advice
- Discuss Strategic Interim
- Explore Leadership Search
- Talk through an agency hire
- Talk through a marketing hire
- Build the right shortlist
- Before you waste six weeks
- Got a tricky role?

Avoid vague or corporate CTAs.

## FAQ Style

FAQs should answer real buyer questions in plain English.

They should be honest, helpful and direct. If retained search is not right, say so. If a salary is light, say so. If Strategic Interim is better than a permanent hire for now, say so.

## Design Note

The design should support the copy. Premium, bold, clean, editorial, commercial and human. Not cold. Not gimmicky.

Current user direction: do not switch to the Manchester palette. Keep the visual system adaptable in `src/styles/theme.css`.
