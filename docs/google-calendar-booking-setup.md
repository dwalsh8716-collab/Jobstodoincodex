# Google Calendar Booking Setup

## Status

Partially ready.

The website has a `/book-a-call` route and booking CTAs that are hidden until a
real Google Calendar Appointment Schedule link is configured.

David still needs to create the booking page in Google Calendar. Codex should
not ask for David's Google password and should not take unrestricted Google
account access.

## Website Approach

Chosen approach:

```txt
Premium external Google Calendar booking link.
```

Reason:

- Google Calendar handles availability, invitations and Google Meet links.
- The website keeps a native, polished page at `/book-a-call`.
- A raw Google iframe can be visually clunky, slower and harder to control on
  mobile.
- The external link is more reliable and has a clear fallback if the URL is not
  configured.

The booking button opens Google Calendar in a new tab.

## Environment Variables

Preferred:

```txt
NEXT_PUBLIC_GOOGLE_BOOKING_URL=
```

Legacy fallback still supported:

```txt
NEXT_PUBLIC_BOOKING_URL=
```

Use the Google Calendar Appointment Schedule booking page link. Do not paste
private Google account links or passwords.

```txt

```

Fields:

- Google Calendar booking link.
- Show booking option on the site?
- Booking button text.
- Booking section heading.
- Booking section intro.
- Show booking in the mobile menu?
- Show booking in the footer?
- Show booking on the contact page?
- Show booking on service pages?

Leave the booking link blank to hide booking CTAs.

## Manual Google Calendar Setup

David should do this in Google Calendar:

1. Open Google Calendar.
2. Click Create.
3. Choose Appointment schedule.
4. Create a 15-minute appointment schedule.
5. Use David's main work calendar.
6. Set the title to `15-minute call with David Walsh`.
7. Add Google Meet as the meeting method/location.
8. Add this description:

```txt
A quick call to sense-check a hiring challenge, strategic interim need, candidate question or market advice.
```

9. Set availability windows David can genuinely protect.
10. Add buffer time if available.
11. Add a sensible minimum notice period.
12. Set a booking window if needed.
13. Limit maximum bookings per day if needed.
14. Keep guest permissions sensible.
15. Use Google confirmation/reminders or adjust them.
16. Add useful booking form questions.
17. Save the schedule.
18. Copy the booking page link.
19. Add it to Railway as `NEXT_PUBLIC_GOOGLE_BOOKING_URL`, or add it in Sanity
    Site Settings when CMS-controlled settings are wired live.
20. Redeploy if the env var changed.
21. Test by booking with another email address.

## Booking Form Questions

Recommended questions:

- Name.
- Email.
- Company.
- Phone, optional.
- What would you like to discuss?
- Are you hiring, looking for work or asking a quick question?

Do not ask for unnecessary sensitive candidate information in the booking form.

## Where Booking Appears

When a booking URL is configured:

- `/book-a-call`
- mobile navigation
- mobile sticky CTA
- contact page
- service page hero CTAs
- homepage final CTA
- clients page final CTA
- footer contact links

Candidate and job routes keep WhatsApp/application routes primary. Booking does
not replace the application flow.

## Analytics

Booking CTAs use:

```txt
booking_click
```

Safe properties:

- location
- page_path
- cta_text
- intent
- service
- booking_type

Do not send names, emails, phone numbers, company names or booking-form answers
to analytics.

Tracking only fires through the existing consent-aware analytics handler.

## Privacy Notes

Booking is handled by Google Calendar. The website should make that clear where
the booking route appears.

The Privacy Policy should mention Google Calendar / booking tools before launch.
This is not legal advice.

## Testing Checklist

Before launch:

- `/book-a-call` returns 200.
- Booking page is noindexed when no booking URL is configured.
- Booking page is added to the sitemap only when a booking URL is configured.
- No booking CTA renders when the URL is missing.
- Booking button opens the Google Calendar booking page when configured.
- Google Meet link is generated by Google Calendar.
- Confirmation email arrives.
- Booking appears in David's Google Calendar.
- Mobile layout works.
- Keyboard focus is visible.
- WhatsApp/email/contact fallback routes work.
- `booking_click` events fire only after analytics consent.
- No PII is sent to analytics.

No extra subscription. No ugly iframe. No passwords in prompts. No faff.
